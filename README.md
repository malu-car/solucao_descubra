
# Descubra Intelligence! 🚀 (Protótipo MVP)

## 📋 Sobre o Projeto

O **Descubra Intelligence!** é um protótipo funcional de uma **ferramenta de operacionalização e gestão** desenvolvido durante o Hackathon. O objetivo principal é demonstrar a viabilidade técnica e o valor de negócio de uma plataforma integrada para otimizar o fluxo de acompanhamento, inscrição e análise estatística de jovens em programas de aprendizagem profissional.

Este repositório contém a Prova de Conceito (PoC) focada nas funcionalidades críticas (core business) do sistema.

---

## 🛠️ Escopo do Protótipo (O que foi implementado)

Para a demonstração do hackathon, focamos no **Fluxo Simplificado** de operação:

* 
**Ferramenta de Gestão:** Interface inicial simulando o acesso dos técnicos responsáveis pelo programa.


* 
**Cadastramento de Jovens:** Módulo funcional para inclusão de novos jovens no sistema com inserção de informações essenciais.


* 
**Registro de Acompanhamentos:** Tela para registrar interações básicas com os jovens (como histórico de evolução).


* 
**Acompanhamento de Métricas (Dashboard):** Painel visual demonstrativo exibindo dados analíticos cruciais para a tomada de decisão.



---

## 🔮 Visão de Futuro (Roadmap de Produção)

O fluxo completo desenhado prevê as seguintes funcionalidades para uma versão final pós-hackathon:

### 1. Flexibilidade no Registro de Acompanhamentos (3 Maneiras)

* 
**Modo Direto Offline:** Aplicativo móvel preparado para funcionar sem internet no campo.


* 
**Formulário Físico:** Modelo impresso padronizado para digitação posterior.


* 
**Escaneamento com IA/OCR:** Captura de fotos de formulários de papel com preenchimento automático de dados no app.



### 2. Ecossistema Integrado (Múltiplos Perfis)

* 
**Portal de Jovens e Familiares:** Área restrita para consulta de frequência, dados cadastrais e cadastro autônomo de habilidades.


* 
**Engajamento:** Direcionamento inteligente para mostras de carreiras e mercado de trabalho.


* 
**Módulo Unidades Formadoras:** Acesso para parceiros de capacitação registrarem acompanhamentos externos com notificações automáticas aos técnicos.



### 3. Analytics Avançado

* 
**Filtro por Território:** Dashboards dinâmicos mostrando a distribuição geográfica e estatística de jovens cadastrados por área regional.
